# MiniChat 项目学习进度

更新时间：2026-09-16

## 一、项目目标

使用现代 C++ 开发一个小型局域网聊天室，学习：

- C++工程目录结构
- CMake编译与链接
- TCP网络编程
- 多线程和线程池
- 配置、日志和数据持久化
- 后期使用Qt制作图形客户端

## 二、当前程序

- `TcpServer`：多线程TCP聊天服务器
- `TcpClient`：命令行聊天客户端
- `Greeter`：模板原有的独立程序

## 三、当前目录职责

- `include/minichat`：公共头文件
- `source`：公共模块的.cpp实现
- `standalone/source`：包含main()的可执行程序
- `test`：单元测试
- `documentation`：项目说明和学习进度

## 四、已经完成的功能

- Winsock初始化和清理
- socket、bind、listen、accept、connect
- TCP消息收发
- 使用换行符解决消息边界问题
- 多客户端同时连接
- 群聊消息广播
- 用户昵称和在线状态管理
- 在线用户查询
- 线程安全的共享客户端集合
- 固定大小线程池
- 任务队列和条件变量
- Worker线程安全停止与join
- 服务端和客户端配置文件
- 日志时间、INFO/ERROR级别
- 日志写入文件
- 日志模块拆分为logger.h和logger.cpp
- 日志文件路径可通过server.conf配置

## 五、配置文件

服务端配置：

- `ip_address`
- `port`
- `worker_count`
- `listen_backlog`
- `log_file_path`

客户端配置：

- `server_ip_address`

## 八、学习方式

按初学者节奏进行：

1. 先讲原理
2. 每次只修改少量代码
3. 逐行解释关键代码
4. 使用动态过程展示变量和线程变化
5. 每个阶段完成后统一测试和提交Git
